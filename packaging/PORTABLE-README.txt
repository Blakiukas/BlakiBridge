BlakiBridge 1.0.4 - Windows x64 portable

EN
Extract the ENTIRE ZIP to a writable folder and run BlakiBridge.exe.
Settings and diagnostics live in the adjacent Data folder. Do not move the EXE alone.
Keep Data when updating and retain portable.flag next to the EXE.
Portable mode does not register installation or Windows startup.
Exit other BlakiBridge copies through their tray menu before launching this copy.
Review monitor calibration when moving to a different computer.

LT
Išskleiskite VISĄ ZIP į aplanką, kuriame galite rašyti, ir paleiskite BlakiBridge.exe.
Nustatymai ir diagnostika saugomi Data aplanke šalia programos. Nekelkite vien EXE.
Atnaujindami išsaugokite Data aplanką. portable.flag turi likti šalia EXE.
Šis variantas neregistruoja diegimo ar automatinio paleidimo su Windows.
Prieš paleisdami uždarykite kitą BlakiBridge kopiją per jos sistemos dėklo meniu.
Kito kompiuterio ekranus ir kalibravimą patikrinkite iš naujo.

RU
Распакуйте ВЕСЬ ZIP в папку с правом записи и запустите BlakiBridge.exe.
Настройки и диагностика сохраняются в папке Data рядом с программой.
При обновлении сохраните Data и файл portable.flag. Не переносите только EXE.
Портативная версия не регистрирует установку и автозапуск Windows.
Перед запуском закройте другие копии BlakiBridge через меню значка в трее.
